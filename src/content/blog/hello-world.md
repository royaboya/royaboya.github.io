## Writing a new post

Drop a new markdown file into `src/content/blog/`. The frontmatter at the top
(the part between the `---` lines) needs a `title`, `description`, and
`pubDate` at minimum. `tags` is optional.

The rest of the file is normal markdown — headings, code blocks, links,
images all work.
